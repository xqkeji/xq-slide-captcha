xq-slide-captcha

滑动拼图验证码前端组件库，TypeScript + SCSS 实现。

配套后端 xqkeji/xq-app-admin：/admin/user/captchadata 生成数据、/admin/user/captchacheck 检验。

GitHub →
本页使用浏览器内模拟后端：图片由 Canvas 现场绘制，答案存在内存里，仅供演示组件交互，没有任何安全性。 要接真实后端，把 src/main.ts 顶部的 USE_REAL_BACKEND 改成 true 即可，请求与响应契约完全一致。
默认 dataUrl / checkUrl 已指向 xq-app-admin 的 /admin/user/captchadata 与 /admin/user/captchacheck；本页用模拟后端替代这两个请求。 切换位置在 src/main.ts 顶部的 USE_REAL_BACKEND = false：改成 true，本页（含二次验证）一起走真实 FetchTransport；实际项目中 init() 不传 transport 即为真实请求。

事件日志

    接入方式

    模块引入（TypeScript / 打包器）

    import { SlideCaptcha } from 'xq-slide-captcha';
import 'bootstrap/dist/css/bootstrap.min.css';          // 先加载 Bootstrap 5.3
import 'xq-slide-captcha/dist/css/xq-slide-captcha.min.css';

const captcha = new SlideCaptcha();

captcha.init({
  handleDom: '.xq-captcha',
  dataUrl: '/admin/user/captchadata',    // xq-app-admin：生成数据
  checkUrl: '/admin/user/captchacheck',  // xq-app-admin：检验
  inputName: 'xq_captcha_token',
});

captcha.onSuccess((token) => console.log('通过', token));

    直接引入构建产物（无打包器）

    把包内 dist/css/ 与 dist/js/ 拷到站点静态目录，页面级实例自动挂到 window.xqSlideCaptcha；弹窗与按钮基于 Bootstrap 5.3，页面需先引入 Bootstrap CSS（IIFE 脚本已内联 Bootstrap JS）。 

    <link rel="stylesheet" href="/static/bootstrap/css/bootstrap.min.css" />
<link rel="stylesheet" href="/static/xq-slide-captcha/css/xq-slide-captcha.min.css" />

<form action="/login" method="post">
  <div class="xq-captcha"></div>
  <button type="submit">登录</button>
</form>

<script src="/static/xq-slide-captcha/js/xq-slide-captcha.min.js"></script>
<script>
  xqSlideCaptcha
    .init({
      dataUrl: '/admin/user/captchadata',
      checkUrl: '/admin/user/captchacheck',
      inputName: 'xq_captcha_token',
    })
    .onSuccess(function (token) { console.log('通过', token); });
</script>

    脚本引入时不用设置 transport：全局实例默认用内置 FetchTransport 请求上面两个地址；自定义传输层请用模块方式。接口由 xq-app-admin 提供，参数口径见 README。
